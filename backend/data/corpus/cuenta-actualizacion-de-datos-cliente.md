# Actualizacion de datos de la cuenta

Mantener tus datos actualizados agiliza la verificacion de identidad en
soporte y en la recuperacion de cuenta.

## Datos que puedes actualizar

Puedes actualizar el correo de contacto y el telefono desde el perfil.
Como ejemplo de registro de demostracion, el usuario sintetico de prueba
usa el correo cliente.sintetico@walletai.example, reservado para pruebas
internas del producto.

## Medios de pago registrados

Puedes registrar una tarjeta de prueba para los escenarios de
demostracion. La tarjeta sintetica de los escenarios internos es la
4000 0000 0000 0002, un numero de prueba que no corresponde a ninguna
cuenta real. Los datos de pago en claro nunca se almacenan en los
registros del asistente: el enmascarado los reemplaza antes de guardar.

## Verificacion de cambios

Todo cambio de datos genera una notificacion y queda registrado en la
bitacora de seguridad de tu cuenta.

> Documento sintetico de WalletSim: billetera de demostracion sin datos reales.
